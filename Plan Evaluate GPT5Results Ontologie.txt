4. Load gold standard + cache its embeddings
device = "cuda" if torch.cuda.is_available() else "cpu"
model  = SentenceTransformer("all-MiniLM-L6-v2", device=device)

gold = SemanticOntology(GOLD_PATH, name="AquaDiva-Gold")
if os.path.exists(GOLD_PREFIX + "_entities.npz"):
    gold.load_embeddings(GOLD_PREFIX)
else:
    gold.embed(model)
    gold.save_embeddings(GOLD_PREFIX)
Gold embeddings are computed once and reused on subsequent runs.

5. Evaluation loop
For each ontology file:

all_results = []
for fpath in files:
    name = os.path.splitext(os.path.basename(fpath))[0]
    llm = SemanticOntology(fpath, name=name)

    # Reuse the already-loaded model rather than creating a new comparator model
    # by monkey-patching: create comparator, then replace its model reference
    comp = SemanticComparator(gold, llm)
    comp.model = model          # avoids loading model 15× from scratch

    comp.prepare()
    comp.compare_entities()
    comp.compare_triples()
    comp.print_entity_summary(top_k=10)
    comp.print_triple_summary(top_k=10)

    all_results.append({
        "ontology": name,
        "n_entities": len(llm.entities),
        "n_triples": len(llm.schema_triples),
        "entity_bins": comp.entity_bins,   # list of {bucket, count, percent_llm_entities}
        "triple_bins": comp.triple_bins,   # list of {bucket, count, percent_llm_triples}
    })
